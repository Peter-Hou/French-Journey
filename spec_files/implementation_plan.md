# Implementation Plan

## Phase 1: Foundation
1. Create the repository structure.
2. Add the project manifest and test harness.
3. Add the static app shell and sample dataset.

## Phase 2: Core logic
1. Implement aggregation functions for daily counts and summary diagnostics.
2. Add the heat map generator and date formatting helpers.
3. Build low-level UI rendering utilities.

## Phase 3: UI features
1. Implement the flashcard rendering and controls.
2. Add the dashboard and question matrix.
3. Ensure responsive styling for mobile and desktop.

## Phase 4: Validation
1. Run the Node test suite.
2. Serve the app locally and verify the rendered page loads without runtime errors.
3. Check accessibility and interaction basics manually.

## Phase 5: Publish
1. Commit the working project.
2. Push to GitHub and enable GitHub Pages.
3. Verify the site loads from the GitHub Pages URL.
